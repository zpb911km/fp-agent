# 扩展插件（Plugin）—— 神经系统，慎写

> 插件不是你的"手"，是**后台钩子**：在 Agent 主流程的关键节点自动回调，做通知/审计/守卫/修改。
> 它不由你主动调用，也不由用户触发——框架事件一到就自动执行。**影响主流程，写错可能让 Agent 无法响应。**

---

## 定位

| 维度 | 插件 vs 工具 |
|------|-------------|
| 触发 | 框架事件自动触发 | LLM function calling 由你主动调 |
| 作用 | 横切关注点：通知、过滤、审计、守卫 | 执行具体任务 |
| 风险 | transform 钩子异常会**阻断主流程** | 只返回结果，不干涉流程 |

**何时用插件**：用户想要"每次回复后通知我 / 拦截包含敏感词的输入 / 记录所有工具调用"这类**横切行为**。

---

## 接口真相（读源码，别背文档）

- **加载器**：`fp_core/plugins/base/plugin.py` → `PluginRegistry.scan()`
- **扫描入口**：`fp_core/core/agent.py`——先 `PluginRegistry(plugin_dir=内置 fp_core/plugins/)`，再按优先级依次 `scan({DATA}/fetched/plugins/)` → `scan({DATA}/public/plugins/)` → `scan({DATA}/private/plugins/)`（同名覆盖并警告）：
  - 单文件：`name.py`（跳过 `_` 开头、`base.py`、`setup.py`、`.disabled`）
  - **目录插件**：含 `__init__.py` 的包（内置 shortcircuit/、task_system/ 就是这样）
- 插件类：继承 `fp_core.plugins.base.plugin.Plugin`
  - 类属性 `name`（唯一，同名覆盖判定键）
  - `on_register(lifecycle)`：在这里用 `lifecycle.register(...)` 注册钩子
  - `on_unregister()`：清理资源
- **钩子枚举**：`fp_core/core/lifecycle.py` → `LifecycleHook`（读它看全部钩子：`ON_INIT`、`ON_MESSAGE_FILTER`、`ON_BEFORE_LLM_CALL`、`ON_BEFORE_RESPONSE`、`ON_TOOL_CALL`、`ON_ERROR`、`ON_SHUTDOWN` 等）
- 钩子分两种：
  - `observe`：只读通知，异常隔离
  - `transform`：可改数据、可阻断流程，**异常上抛会卡死主流程**
- `lifecycle.register(hook, func, priority=100, name=..., hook_type="observe")`
- **输出方式（关键）**：插件**没有终端输出 API**（不存在 `fp_core.display`）。信息要进对话/给用户看，只有两条路：
  ① 注册工具：`tool_registry.register_tool(name, definition, executor)`，`executor` 返回字符串（shortcircuit 范例，工具调用的返回值会展示给用户）
  ② transform 钩子改 `HookContext.data/metadata` 或修改 messages/response 数据（task_system 范例，在 `ON_AFTER_LLM_CALL` 附加任务状态）
  ⚠️ 不要 `print()`——污染 stdout，子 agent 模式会泄漏

## 动手步骤

```
① 读 fp_core/core/lifecycle.py 的 LifecycleHook 枚举，选对钩子
② 读内置 shortcircuit 范例（fp_core/plugins/shortcircuit/plugin.py）
③ 在 {DATA}/private/plugins/ 新建 <名>.py（或 <名>/__init__.py 目录包）
④ 实现 on_register 注册钩子
⑤ 输出：注册工具返回字符串 / transform 钩子改 HookContext（见上），不要 print()
⑥ bash 验证 + 请用户 /reload
```

## 验证

```bash
python3 - <<'PY'
import importlib.util
from fp_core.plugins.base.plugin import Plugin
p = "{DATA}/private/plugins/你的插件.py"
spec = importlib.util.spec_from_file_location("plg", p)
m = importlib.util.module_from_spec(spec); spec.loader.exec_module(m)
# 找出模块里的 Plugin 子类
cls = [v for v in vars(m).values() if isinstance(v, type) and issubclass(v, Plugin) and v is not Plugin][0]
inst = cls()
print("OK:", inst.name)
PY
```

> ⚠️ transform 钩子异常会阻断流程——先让用户小范围测试，确认无误再长期启用。
