# 技能与记忆（Memory / Skill）—— 你的知识库

> 记忆是你（FP）唯一能**主动读写**的持久化机制，也是自举最重要的沉淀手段。
> 每次学到新东西、完成新任务，都应考虑存进记忆，下次会话才能复用。

---

## 定位

- **记忆 = 跨会话持久化知识**。新会话开始时，系统提示词会自动附带**记忆索引**（全部记忆的 name + type 摘要）；需要详情时你用工具读取正文。
- **技能 = 一种记忆**（`type: skill`）。过去的 `skills/` 目录是旧版，新体系统一放 `memory/`。
- 由你通过 `memory_save` / `memory_read` 工具读写——**这是你能主动调用的**。

---

## 存储位置

```
全局:   {DATA}/private/memory/<名称>.md     ← 所有项目可见（三来源最高优先级）
本地:   <当前项目>/.fp/memory/<名称>.md     ← 仅当前项目
```

每个记忆文件 = **YAML frontmatter + Markdown 正文**：

```markdown
---
name: my_skill
description: 一句话描述（用于索引/检索，务必精炼）
type: skill          # skill / project / user / feedback / reference
created: 2026-08-02
---

# 正文
……

```

---

## 工具用法（你主动调）

```python
# 保存
memory_save(root="~", category="skill", name="my_skill",
            description="一句话描述",
            content="记忆正文")

# 读取
memory_read()                     # 全部索引
memory_read(name="my_skill")      # 精确读
memory_read(query="关键词1 关键词2")  # AND 全文搜索
memory_read(path="~/skill")       # 浏览某分类
```

---

## 什么时候记（判断准则）

| 场景 | type |
|------|------|
| 用户表达了长期偏好 | `user` |
| 完成了一个可复用的任务/技巧 | `skill` |
| 项目关键决策/架构 | `project` |
| 本次会话的教训 | `feedback` |

**原则：**
1. 记**结论**和**关键步骤**，不记流水账
2. 技能要**可复现**：写清何时用、参数、示例
3. 一个文件一个主题
4. `description` 是检索命中的关键——写得精准
5. 记忆也有寿命：过时的旧记忆要主动更新/删除，避免索引污染
