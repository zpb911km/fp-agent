# 工具概览

## 核心工具（直接绑定）

以下工具直接绑定到系统核心，作为内置工具，始终可用。

| 工具名 | 说明 |
|--------|------|
| `bash` | 执行任意 shell 命令，支持管道/重定向，超时 300 秒。跨平台：Linux/macOS 原生执行；Windows 有 Git Bash 时走 bash.exe（Unix 命令），无 Git Bash 时降级 cmd.exe（Windows 命令）。危险命令（`rm -rf /`、`mkfs`、`shutdown` 等 BLOCK 规则）执行前**向用户求批**（headless 无 io 时回落拦截提示），`force=true` 仍可放行；`background=true` 移交后台立即返回 `job_id`；**超时默认自动转后台**继续执行并返回 `job_id`（`on_timeout="kill"` 才杀掉） |
| `read_file` | 读取文件内容，支持指定行范围和行数限制 |
| `write_file` | 创建新文件或覆盖已有文件 |
| `edit_file` | 对文件进行精确字符串替换（只替换首次出现的位置） |

这些工具是 Agent 与操作系统交互的基础设施，所有文件操作和命令执行都依赖它们。

---

## 插件工具

以下工具通过插件系统提供，可按需调用。

| 工具名 | 说明 |
|--------|------|
| `memory_read` | 读取长期记忆（空查询列出全部，关键词搜索） |
| `memory_save` | 保存一条长期记忆到持久化存储 |
| `python` | 执行 Python 代码，适合复杂数据处理和算法验证 |
| `subagent` | 派遣子 Agent 执行独立任务，节省主上下文 Token |
| `web_fetch` | 抓取并解析网页内容，返回纯文本 |
| `shortcircuit` | 短路已完成的连通块，移除工具调用细节 |
| `reload` | **两段式热重启——会重启 FP 进程本身**。先不带 token 调用，取回隔离测试告示与动态口令（15 分钟、一次性）；在子进程完成隔离测试后，再携口令二次调用才真正重启：会话落盘、写 handoff、按启动命令 execve，新实例恢复会话续接。失败全回滚，进程不死 |
| `ask_user` | **pull 式人类交互**：向用户提问并阻塞等待回答。结构化契约 v2：`options` 让三前端渲染一键选择按钮/编号列表，`suggest` 渲染推荐徽章（空回车采纳），`timeout` 有界等待（默认 300s，超时返回 `timeout`），`ask_id` 对账收据与注入。回答以**裸文本** user 消息在环顶注入（无标头 = 人类输入，身份协议见 `docs/dev/引擎.md`），工具只返回收据（人类话语不落 tool result）；ACP 无带内回复通道 → `deferred`（问题展示、回答走下一轮，不伪造）。防滥问纪律：只问阻塞级决策、必须给 `suggest`；子 agent（无 io）返回 `unavailable` |
| `wait_job` | 阻塞等待后台任务完成并取回结果文件路径——精确在完成一刻返回（无 sleep 轮询）。超时未完成返回 `still_running`，可再次等待 |
| `kill_job` | 终止后台任务（整个进程组，如 bash 的 killpg），用于中止失控/不再需要的任务 |
| `list_jobs` | 列出后台任务（框架事实表，可见性独立于 LLM）。**硬性筛选**：本会话全部任务 + 仍在运行的跨实例任务，按 running→done→failed→killed 排序、空 error 字段省略；跨会话已结束的任务不显示（完成时已注入，结果文件仍可按 id 直读） |

> **后台任务机制：** `bash` 的 `background=true` 把执行移交后台，**命令超时也默认自动转后台**（均返回 `job_id`；`on_timeout="kill"` 才杀掉）；任务状态独立落盘 `$TMPDIR/fp_jobs/`（死进程遗留自动清扫为 `killed`；落盘文件按 id 永久可查，但 `list_jobs` 只显示本会话任务与跨实例活任务，跨会话终态不返回）。完成后在**下一次 LLM 调用前**由框架环顶注入 `【系统事实】…已完成，结果见 <path>`（user 角色、带 `⁂[kind]` 身份标头，见 `docs/dev/引擎.md`「注入消息身份协议」）。会话退出时未完成任务统一清算为 `killed`。设计依据见 `docs/dev/ASYNC_AGENT_DESIGN.md`。

> **⚠️ reload 警告：** 二次调用是**真正重启当前进程**——未落盘的工作会丢，正在跑的交互会中断。子进程调用、缺启动快照（`FP_LAUNCH_JSON`）时直接拒绝；口令一次性，过期需重新获取。

> **任务工具：** `task_create` / `task_read` / `task_update` / `task_edit` / `task_list` / `task_clear` 由**任务系统生命周期插件**自动注册（操作**任务图** taskmap），不在此表中列出。该插件还负责在每次 LLM 调用前自动附加 `[task]` 进度提醒。参见 [任务系统插件说明](../dev/工具系统.md#插件工具)。

> **用户级工具：** 除内置外，用户目录 `~/.local/share/fp/tools/` 可新增/覆写工具（如本机部署的 `web_search`、`vision`、`kdeconnect_*` 等），随部署环境不同而不同。

整个工具调用的生命周期如下：

```
用户输入
    │
    ▼
LLM 思考（分析意图、决定调用的工具和参数）
    │
    ▼
调用工具（系统执行对应的工具函数）
    │
    ▼
结果返回 LLM（工具输出作为上下文的一部分）
    │
    ▼
LLM 生成最终回复（基于工具结果组织语言）
    │
    ▼
回复用户
```

### 终端显示

工具调用过程会实时在终端显示，以 `🛠️` 图标标识：

```
🛠️ 正在调用工具: bash(command="ls -lh ~/.local/share/fp/sessions/")
🛠️ 工具执行完毕（耗时 0.32s）
```

这使得整个过程对用户透明，可以看到 Agent 每一步的操作和耗时。
