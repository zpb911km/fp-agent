# 扩展工具（Tool）—— 你的手

> 工具是你（FP）唯一能主动调用的扩展方式。**这是自举的核心。**

---

## 定位

工具通过 LLM Function Calling 机制暴露给你。当你决定"我需要执行某个操作"时，LLM 会从工具列表中挑选并调用它，框架执行后把字符串结果还给你。

**与命令/插件的区别：**
- 工具 = 你能主动调（function calling）
- 命令 = 用户输入 `/xxx`（你触发不了）
- 插件 = 后台钩子（自动触发，不是你的手）

---

## 接口真相（读源码，别背文档）

- **加载器**：`fp_core/tools/__init__.py` → `ToolRegistry._load_from_dir()`
- 加载规则：扫描三来源 `{DATA}/{fetched,public,private}/tools/extensions/` 下**以 `_plugin.py` 结尾**的文件；优先级 private > public > fetched，同名后加载覆盖并警告
- 两种形态（加载器里写得很清楚，读它）：
  - **单工具**：模块级 `PLUGIN_DEFINITION`（OpenAI schema）+ `execute(params) -> str`
  - **多工具**：`PLUGIN_DEFINITIONS`（list）+ `TOOL_MAP`（{工具名: executor}）
- 执行函数必须返回 `str`（LLM 只收字符串）；出错就 `raise Exception`，框架会捕获转成错误消息
- **核心工具不可覆盖**：`bash` / `read_file` / `write_file` / `edit_file` 硬绑定，不要试图同名覆盖

---

## 范例（抄这些，别自己发明）

```
<安装目录>/fp_core/tools/extensions/
```

---

## 动手步骤

```
① 读加载器源码 30 秒，确认接口
② cp 一个最像的范例到 {DATA}/private/tools/extensions/<你的名>_plugin.py
③ 改 schema 的 name/description/parameters + execute 实现
④ bash 验证（见下）
⑤ 请用户 /reload（或重启），再让 LLM 自然发现新工具
```

---

## 验证

```bash
python3 - <<'PY'
import importlib.util
p = "{DATA}/private/tools/extensions/你的工具_plugin.py"
spec = importlib.util.spec_from_file_location("t", p)
m = importlib.util.module_from_spec(spec); spec.loader.exec_module(m)
if hasattr(m, "PLUGIN_DEFINITIONS") and hasattr(m, "TOOL_MAP"):   # 多工具
    print("multi:", [d["function"]["name"] for d in m.PLUGIN_DEFINITIONS])
elif hasattr(m, "PLUGIN_DEFINITION") and hasattr(m, "execute"):  # 单工具
    print("single:", m.PLUGIN_DEFINITION["function"]["name"])
    # 可加：await m.execute({...}) 冒烟测试
else:
    raise SystemExit("缺接口：单工具需 PLUGIN_DEFINITION+execute，多工具需 PLUGIN_DEFINITIONS+TOOL_MAP")
PY
```

**生效需要用户 `/reload`**——你自己无法触发重载。若用户不配合，可提示重启 `python -m fp`。
