# 插件系统

## 架构

插件系统采用**生命周期钩子驱动**的架构。系统在运行的关键节点触发钩子，已注册的插件按优先级依次执行对应的钩子函数。

**工作流程**

```
[系统事件] ──触发──→ [钩子调度器] ──依次调用──→ [已注册的插件钩子函数]
```

---

## 生命周期钩子

系统共定义了 **15 个生命周期钩子**（8 transform + 7 observe），按阶段分组。`transform` 钩子可修改流程（过滤消息、改写 LLM 入参/出参、拦截工具），`observe` 钩子仅通知不可修改。

| 阶段 | 钩子 | 类型 | 触发时机 |
|------|------|------|----------|
| **初始化** | `ON_INIT` | observe | Agent 初始化完成 |
| | `ON_CONFIG_LOADED` | observe | 配置加载完成 |
| **消息处理** | `ON_MESSAGE_FILTER` | **transform** | 用户消息过滤/修改 |
| | `ON_MESSAGE_RECEIVED` | observe | 消息已接收（仅通知） |
| **LLM 调用** | `ON_BEFORE_LLM_CALL` | **transform** | LLM 调用前 — 可修改 messages/tools 或取消 |
| | `ON_AFTER_LLM_CALL` | **transform** | LLM 返回后 — 可修改 response 或阻止工具 |
| **响应** | `ON_BEFORE_RESPONSE` | **transform** | 返回响应前 — 可修改 content |
| **工具** | `ON_TOOL_SELECT` | **transform** | 工具已选择 — 可修改列表/阻止执行 |
| | `ON_TOOL_CALL` | **transform** | 工具即将调用 — 可修改参数/暂停/拒绝 |
| | `ON_TOOL_RESULT` | **transform** | 工具调用完成 — 可审查/修改/过滤结果 |
| | `ON_TOOL_ERROR` | **transform** | 工具出错 — 可处理/覆盖错误 |
| **上下文** | `ON_CONTEXT_UPDATE` | observe | 上下文已更新 |
| **错误** | `ON_ERROR` | observe | 发生错误 |
| **资源** | `ON_SHUTDOWN` | observe | 关闭中 |
| | `ON_CLEANUP` | observe | 清理资源 |

## 内置插件

### 通知插件

在交互式模式下，通知插件在以下时机触发桌面通知和提示音：

- `ON_AFTER_LLM_CALL`：Agent 回复完成后，发出通知提醒用户查看
- `ON_ERROR`：发生错误时，发出告警通知

通知通过 `kdeconnect_notify` 工具（用户级）可同步推送到手机。

### 任务系统插件

通过 `ON_INIT` 注册 `task_create` / `task_update` / `task_list` / `task_clear` 四个任务工具；`ON_BEFORE_LLM_CALL` 自动附加任务进度提醒。

### shortcircuit 插件

通过 `ON_INIT` 做两件事：
1. 注册 `shortcircuit` 工具（工具层硬性策略：当前块强制退化、其他块默认 crop）
2. 通过 `register_command("sc", command)` **注入 `/sc` 命令**（不走 commands/ 自动发现；插件被禁用时 `/sc` 一并消失）

## 插件开发概览

### 开发步骤

1. 继承 `Plugin` 基类
2. 实现 `on_register` 方法
3. 在 `on_register` 中用 `lifecycle.register(LifecycleHook.ON_XXX, handler)` 注册钩子
4. 将插件文件放入插件目录（内置 `fp_core/plugins/` 或用户三来源目录，默认 `~/.local/share/fp/private/plugins/`）

### 最小示例

```python
from fp_core.core.lifecycle import LifecycleHook
from fp_core.plugins.base import Plugin

class HelloWorldPlugin(Plugin):
    """一个简单的示例插件"""

    def on_register(self, lifecycle):
        """注册钩子"""
        lifecycle.register(LifecycleHook.ON_INIT, self.on_start, name="hw_start")
        lifecycle.register(LifecycleHook.ON_MESSAGE_RECEIVED, self.on_user_message, name="hw_msg")

    async def on_start(self, ctx, **kwargs):
        """系统启动时执行"""
        print("👋 HelloWorld 插件已加载")

    async def on_user_message(self, ctx, **kwargs):
        """收到用户消息时执行"""
        content = ctx.data.get("content", "")
        if "hello" in content.lower():
            print("🌍 用户说了 hello！")
```

### 钩子函数签名

所有钩子函数均为异步函数，接收与触发时机相关的上下文参数。具体参数请参考基类中的类型注解。
