# 扩展命令（Command）—— 用户的键盘，不是你的手

> ⚠️ **先读这一句**：斜杠命令是**用户在终端输入**的界面。你在对话循环中**永远无法主动触发** `/xxx`。
> 你能做的是：帮用户**编写**命令文件，然后由用户自己测试。写命令不是为了让你自己用。

---

## 定位

命令 = 用户在 CLI 输入 `/命令名 参数` 触发的动作（如 `/session`、`/reload`、`/history`）。

**你（FP）与命令的关系：**
- ❌ 你不能主动调用命令
- ❌ 你不能用命令做验证（`/reload`、`/option list` 都是用户界面）
- ✅ 你可以帮用户新增命令 → 用户以后输入 `/xxx` 就能用
- ✅ 命令文件本身是普通 `.py`，你可以读、可以写

---

## 接口真相（读源码，别背文档）

- **加载器**：`fp_core/commands/__init__.py` → `_discover_commands()`
- 加载规则：扫描 `{DATA}/commands/` 下所有 `.py`（排除 `__init__.py`）
- 模块级接口：
  - `name: str` —— 命令名（不含 `/`），**必填**
  - `execute(state, arg) -> tuple[bool, str]` —— **必填**，同步或异步均可
  - `aliases: list[str]` —— 可选别名
  - `description: str` —— 帮助文本（`/help` 用）
- `execute` 第一个参数是 `state`（`State` 对象，含 `conversation/session/llm/lifecycle/plugins/tool_exec/io/token_tracker`，还有 `state.agent` 回引 Agent），第二个是命令参数原始字符串
- 返回 `(True, "输出")` 表示已处理并输出；返回 `False` 表示未处理
- **同名覆盖**：用户目录文件与内置同名 → 用户版本生效（先加载内置，后加载用户）

## 动手步骤

```
① 读 fp_core/commands/history.py（最小可读范例）
② 在 {DATA}/commands/ 新建 <命令名>.py
③ 实现 name + execute
④ bash 语法验证（见下）
⑤ 告知用户：请 /reload 或重启，然后输入 /你的命令 测试
```

## 验证

你无法自己触发命令，只能做**静态验证**：

```bash
# 语法 + 接口检查
python3 -c "
import importlib.util
spec = importlib.util.spec_from_file_location('c', '{DATA}/commands/你的命令.py')
m = importlib.util.module_from_spec(spec); spec.loader.exec_module(m)
assert hasattr(m, 'name') and hasattr(m, 'execute'), '缺接口'
print('OK:', m.name)
"
```

> 命令的真实验证只能靠用户输入 `/xxx`。你可以写完后请用户测一下。
